# Workspace Backup

**Workspace Backup** 是账号所有人自用的开发工作区备份工具。
它将本人选定的本机文件和数据库一致性副本先在本机加密，再保存到本人 Google Drive。
它还用于读取备份、验证完整性和按既定保留规则管理本应用的旧备份版本。
该工具不提供公共注册或其他人的备份服务。

本应用请求 `https://www.googleapis.com/auth/drive.file` 权限。
这个范围用于访问本应用创建的文件，以及用户明确向本应用授权的特定文件。
本应用不请求整个 Google Drive 的读写权限。

## 隐私声明

### 访问和保存的数据

本应用访问账号身份、存储额度、本应用备份目录及其中的备份文件，
用于确认目标账号、检查容量、上传、下载、校验和管理备份版本。
原始备份内容在本机加密，Google Drive 保存的是加密备份内容。

OAuth 客户端配置和访问令牌保存在本机加密配置中；恢复所需的配置也可以
作为加密文件保存在同一私人备份目录。恢复密码由账号所有人独立保管。

### 数据使用和共享

这些信息仅用于账号所有人的备份与恢复工作。
本应用不出售数据，不用于广告，不把备份内容公开或分享给其他用户，
也不将其用于训练模型。Google Drive 自身的数据处理仍适用 Google 的相关政策。

### 保留与控制

备份按所有人设定的保留规则管理。仅在新的云端副本通过校验后，才会按规则轮换
本应用管理的旧备份版本。失败不会自动缩短既定的成功日期保留数量。
本应用不清理其他 Google Drive 文件。

账号所有人可以停止本机备份任务、通过 Google 账号撤销授权，并自行管理 Google Drive
中保存的备份。撤销访问权限不等于已经删除现存的备份文件。
